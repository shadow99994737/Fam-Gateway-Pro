Features

Everything a payment gateway needs

Built specifically for FamPay UPI — automated, self-hosted, and fully under your control.

Instant Auto-Verify

Gmail IMAP scans your inbox for FamPay credit mails and matches UTR + amount in seconds — zero manual checking.

Payment Links & QR

Generate shareable checkout links or dynamic QR codes for any amount, with live status polling built in.

Developer REST API

Create orders and verify payments from any backend, bot, or app with a simple API key.

Full Admin Panel

Manage users, plans, orders, and settings from one dashboard — ban/extend users, add plans, track revenue.
